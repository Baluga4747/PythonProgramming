# Dungeon Adventure Game

## Overview

Dungeon Adventure is a Python text-based game where the player explores an endless dungeon filled with enemies, treasure chests, traps, resting areas, and quiet rooms. The goal is to explore as many rooms as possible while managing health, potions, and gold.

The player can fight enemies, attempt to flee from combat, collect rewards, recover health, save progress, and retire from the dungeon.

## Requirements

- Python 3.10 or newer recommended.
- Internet connection for downloading the required packages.
- A code editor such as Visual Studio Code or IDLE.

## Packages to Install

The game uses Python's built-in modules for features such as JSON data handling, random events, file paths, and CSV files. These do not need to be installed separately.

Install the following external packages:

```bash
pip install pandas
```

**Pandas** is used to create game statistics, summarize room history, and export reports to CSV files.

If you use multiple Python installations, you may need to run:

```bash
python -m pip install pandas
```

## Project Files

Keep the game files together in the same project folder.

- `dungeon.py` — Main game program.
- `dungeon_data.json` — Contains game settings, enemies, rooms, traps, chests, weapons, and potions.
- `dungeon_save.json` — Stores saved game progress when generated by the program.
- `room_log.csv` — Records information about rooms explored during a completed run.
- `dungeon_stats.csv` — Contains summarized statistics grouped by room type.
- `event_log.csv` — Records events that occur during the game.
- `README.md` — Instructions and project documentation.

The save and report files may not exist until the game creates them.

## How to Start the Game

1. Install Python.
2. Install Pandas using the command listed above.
3. Place `dungeon.py` and `dungeon_data.json` in the same folder.
4. Open a terminal or command prompt in that folder.
5. Run the game:

   ```bash
   python dungeon.py
   ```

6. Follow the instructions displayed in the terminal.

If the program cannot find the game data file, make sure `dungeon_data.json` is in the correct folder and that the filename matches exactly.

## How to Play

### Main Menu

Use the menu options displayed by the game to choose an action. Available actions may include:

- **Explore** — Enter the next dungeon room.
- **View Stats** — Check your current player information and progress.
- **Use Potion** — Use an available potion.
- **Save Game** — Save your current progress.
- **Save and Quit** — Save your progress and exit the game.
- **Retire** — End your run and generate the final reports.

Choose the number or option requested by the program.

### Exploring Rooms

Each time you explore, the game generates a room with a random description and room type.

The five room types are:

- **Combat Room:** Encounter an enemy and choose whether to attack, use a potion, or attempt to flee.
- **Chest Room:** Decide whether to open a chest and collect possible rewards.
- **Trap Room:** Take damage from a randomly selected trap.
- **Rest Room:** Recover a random amount of health without exceeding your maximum health.
- **Quiet Room:** Explore a room without encountering an event that changes your resources.

### Combat

During combat, monitor both your health and the enemy's health.

- **Attack:** Deal a random amount of damage to the enemy.
- **Use Potion:** Apply an available potion's effect.
- **Flee:** Attempt to escape combat. Fleeing may fail and leave you vulnerable to an enemy attack.

Defeating an enemy can reward you with gold. If your health reaches zero, your run ends.

### Potions and Rewards

Potions can provide healing or other effects, depending on the potion type. Potions found in chests can replenish your inventory.

Gold and other rewards may be collected by defeating enemies or opening chests.

### Saving and Ending a Run

Save your progress using the save option when available. If you choose to save and quit, the game should save before exiting.

You can retire from the dungeon when you want to end your run. The game then generates summary reports based on your exploration and recorded events.

## Generated Reports

When a run ends, the program uses Pandas to organize the recorded information and generate reports.

- `room_log.csv` — Room-by-room information, including room types, encounters, outcomes, damage, and health changes.
- `dungeon_stats.csv` — Summary statistics grouped by room type.
- `event_log.csv` — A timeline of game events, including combat actions and potion use.

Open the CSV files with Microsoft Excel, Google Sheets, or another spreadsheet application.

If your version of the game generates a final text summary when you retire, that file contains a readable overview of the run and its reports.

## Troubleshooting

**Pandas is missing:** Run `python -m pip install pandas`.

**The game data file cannot be found:** Confirm that `dungeon_data.json` is in the same folder as `dungeon.py`.

**The game will not resume:** Check that the save file exists and contains valid data. Do not delete or overwrite a save file you want to recover.

**Reports are missing:** Confirm that the run ended and check the terminal for any file-writing errors.

## Tips

- Keep an eye on your health before entering another room.
- Use potions strategically.
- Consider fleeing when an enemy is too strong.
- Save your progress regularly.
- Review the CSV reports after a run to see how far you explored and how many resources you used.
